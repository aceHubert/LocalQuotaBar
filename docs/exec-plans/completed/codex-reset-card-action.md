# Codex 重置卡逐行操作

- 状态：已完成
- 创建日期：2026-09-15
- 最后更新：2026-09-15

## 目标

每张 Codex 重置卡明细后提供按钮，经 app-server 传入该卡 creditId；同一时刻仅一张卡可提交，失败复用幂等键，成功清理键并刷新额度、重置卡数量。

## 范围

- 包含：卡片 ID/状态解析、stdio RPC、按账号和卡保存幂等键、按钮状态、刷新与账号切换保护。
- 不包含：实际执行额度或重置请求、启动应用验证、打包安装；用户手工验证结果。

## 背景

- 相关代码：main.swift、QuotaPanelViews.swift、ProviderPanelSections.swift。
- 相关规范：docs/PLANS_GUIDE.md、docs/HISTORY_GUIDE.md。
- 仓库已有大量未提交修改，任务前快照作为增量统计基线。

## 风险

- 超时可能发生在服务端成功后：按账号和卡保存幂等键，重试复用，alreadyRedeemed 视为成功。
- 旧缓存没有卡 ID：继续显示，按钮禁用，当前账号刷新成功后启用。
- 并发刷新及账号切换可能混入旧数据：提交期间禁用账号切换，刷新检查账号归属，重置后保证追加刷新。
- 回滚方式：仅回退本任务增量；保留既有修改和待确认幂等记录。
